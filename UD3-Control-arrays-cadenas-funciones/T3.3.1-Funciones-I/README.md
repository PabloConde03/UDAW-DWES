# T3.3.1 · Funciones (I)

| Módulo | Unidad | Tipo | Temas |
|---|---|---|---|
| MP0613 · DWES | UD3 · Funciones | Ejercicios | Definición de funciones, valor de retorno, reutilización |

---

## Ejercicio 1

Escribe una función PHP que, dado un número, indique si es par o impar.

## Ejercicio 2

Escribe una función PHP que, dado un número, indique si es primo o no.

## Ejercicio 3

Escribe una función PHP que, para cada número del 1 al 10, muestre si es par o impar y, además, muestre un mensaje si el número es primo. Los cálculos para saber si el número es primo deben estar en una función, y los de par o impar, en otra.
